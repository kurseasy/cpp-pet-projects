# Calculator

A simple console-based calculator written in C++.

## Overview
This project implements a basic calculator that performs fundamental arithmetic operations. It serves as a practical example of core C++ concepts and structured programming.

## Features
- Performs basic operations: addition, subtraction, multiplication, and division.
- Clear console interface with user prompts.
- Error handling for invalid inputs and division by zero.

## What it demonstrates
- Use of `switch` statement for operation selection.
- Input/output handling using `cin` and `cout`.
- Basic C++ syntax and program structure.
- Conditional logic and flow control.

## Usage
1. Run the compiled program.
2. Enter the first number when prompted.
3. Enter the second number when prompted.
4. Select an operation by entering the corresponding symbol (+, -, *, /).
5. View the result.
6. Choose to perform another calculation or exit.

## Possible Enhancements
- Support for more operations (e.g., exponentiation, modulus).
- Memory functions (store/recall values).
- History of calculations.
- Graphical user interface (GUI).

## How to build and run

### Prerequisites
- A C++ compiler (e.g., g++, clang++, or MSVC)

### Compilation
```bash
g++ main.cpp -o calculator
```

### Execution
```bash
./calculator
```
