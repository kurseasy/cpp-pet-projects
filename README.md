# C++ Pet Projects

Набор небольших проектов на C++, созданных для демонстрации базовых навыков языка.  
Каждый проект показывает отдельные аспекты: синтаксис, ООП, работа с памятью, STL, логика и работа с файлами.

## Список проектов
- **calculator/** — простой калькулятор с использованием `switch`.
- **student-class/** — пример класса "Студент" с конструктором и методом.
- **word-counter/** — программа для подсчёта частоты слов с использованием `std::map`.
- **tic-tac-toe/** — игра "Крестики-нолики" с использованием ООП и логики.
- **file-manager/** — программа для работы с файлами (чтение и запись).

## Как запустить
1. Перейдите в папку проекта:
   ```bash
   cd calculator
2. Скомпилируйте:
   ```bash
   g++ main.cpp -o program
3. Запустите:
   ```bash
   ./program
